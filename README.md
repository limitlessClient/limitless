Готовые сборки клиента и лаунчера находятся в Releases. История изменений находится в CHANGELOG.md.

При публикации релиза GitHub Actions обновляет manifest.json, devlog.json и сайт.
Сайт и лаунчер используют общую историю из devlog.json.
